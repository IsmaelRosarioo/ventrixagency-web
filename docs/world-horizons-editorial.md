## 5. INTERACTIVE COMPONENT BEHAVIOR & CODE READY INTERFACES

### 5.1 Horizon Data Model (`TypeScript`)
```typescript
export interface WorldHorizon {
  id: string;
  index: string; // e.g. "01"
  name: string;
  kicker: string;
  title: string;
  narrative: string;
  imageSrc: string;
  imageAlt: string;
  telemetry: {
    elevationRange: string;
    hazard: string;
    strategicYield: string;
    dominantInfrastructure: string;
  };
  vector: {
    coordinates: string;
    sector: string;
    bluemapCoordinates: { x: number; y: number; z: number; zoom?: number };
  };
}
```

### 5.2 Micro-Interactions & State Transitions
1. **Horizon Tab Selection**:
   - Clicking any tab smoothly transitions the primary cinematic image with a gentle cross-dissolve (`duration: 0.6s`, easing: `[0.16, 1, 0.3, 1]`).
   - The active tab illuminates with a crisp white perimeter border, while muted tabs maintain a 40% translucent obsidian appearance.
2. **Telemetry Drawer Expansion**:
   - Default view presents Kicker, Monumental Title, and Elevation badge.
   - Users can tap "Telemetry Dossier" to expand the 4-point telemetry breakdown (Elevation, Hazard, Yield, Infrastructure).
3. **"Verify on 3D BlueMap" Action Trigger**:
   - Prominently positioned on the bottom right of the telemetry card.
   - Clicking launches the interactive BlueMap modal with the exact camera vector pre-loaded, delivering immediate visceral proof of in-engine reality.
4. **Keyboard Accessibility**:
   - Left/Right arrow keys navigate sequentially across horizons (`01` through `06`).
   - Spacebar or Enter toggles the Telemetry Dossier expansion.
